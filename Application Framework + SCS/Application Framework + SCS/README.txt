These are training materials that were created to introduce a new developer 
to two most important concepts in AIS framework:

- the application framework  ( AF)
- and the communication system  ( SCS ).


The contents covered are a rehash of some other materials that may be 
either version controlled in autonomy git repos or available on some shared drive.


At this moment, only part 3 & part 4 have been written.
Part 1 & part 2 are to be written.


When providing training, it is highly suggested that part 1 is covered first, then part 2 and so on.

SCS-protocol-v1.5.pdf 

-  This document was written based on a request from VIMS/PLElite engineers 
   who wanted to learn more about SCS protocol.
   This was needed to help with the protocol selection for communication 
   between PL671 and VIMS/PLElite.

-  SCS-protocol-v1.5.pdf is not the final protocol document.
   This is more an introduction to SCS.
   At the same time, it makes numerous references to AIS Application Framework.

-  SCS-protocol-v1.5.pdf document was presented to VIMS/PLElite engineers
   and (I think) helped them understand SCS.  
   At the same time, it exposed them to AIS AF.

-  Moving forward:
   Based on questions from the audience,  SCS-protocol-v1.5.pdf should be improved
   to clarify a number of items and provide additional clarifications how an application
   logic would use SCS.

   The next step is to create AIS-part1-scs.pdf  ( equivalent to AIS-part[3|4]*.pdf documents ).
   This document shall be a self paced tutorial on scs.
   This document shall have simple code snippets showing example SCS uses.

   Finally, a proper SCS protocol document shall be written.
   It should use SCS-protocol-v1.5.pdf as its base ( with all references to AIS AF removed 
   and other unrelated references ).
