WeighApp <-> JobMgr: direct communication channels
=====================================================
Derived by cross-referencing the "Interfaces" hash in both apps' config files:
  config/LpsSaWeighApp.rb
  config/LpsSaJobMgrApp.rb
Rule used: same channel base name, with Output on one app's side and Input on
the other app's side, = a real point-to-point channel between the two apps.
Same base name with Input on BOTH sides = both apps independently subscribe
to some third process's publisher (not a direct channel between them).
